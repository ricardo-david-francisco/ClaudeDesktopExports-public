## At a glance

<table>
  <tr><td width="190"><b>What the app does</b></td><td>A Windows tray app: reads the conversation files Claude Desktop keeps on the PC and writes each conversation as a Markdown file and an HTML page, searchable, with each Windows user seeing only what its role allows.</td></tr>
  <tr><td width="190"><b>Google Drive</b></td><td>Optional. Asks Google only for <code>drive.file</code> (the files the app itself creates), <code>openid</code> and <code>email</code>. Never deletes anything in Drive.</td></tr>
  <tr><td width="190"><b>Data</b></td><td>No server and no telemetry: nothing is sent to the developers. The Google sign-in stays on the PC, encrypted for the Windows user.</td></tr>
  <tr><td width="190"><b>This repository</b></td><td>The three pages Google's sign-in links to, generated by the brand. No code of the app.</td></tr>
</table>
